**القانون الحاكم لتماسك الآلات والقطع الميكانيكية، ومنع انفصال الأجزاء، والتدقيق الفيزيائي الإلزامي قبل الرندر.**

---

## 🎯 تشخيص المشكلة الجذرية: لماذا تخرج القطع "كل شغلة في شقة"؟
عند رسم آلة معقدة (مثل حفارة هيدروليكية، ذراع روبوت، أو محرك مركب):
* **الخطأ القديم:** رسم كل قطعة بإحداثيات تقديرية شاشية عامة (`Absolute Guessing Coordinates`):
  * رسم الجنزير في نقطة `(x1, y1)`
  * رسم الكابينة في نقطة `(x2, y2)` بعيدة عنها
  * رسم الذراع في الهواء لا يلامس الكابينة!
  * رسم المجرفة تطفو في الفراغ بدون ذراع يمسكها!
* **النتيجة الكارثية:** مشهد مفكك ومضحك يفتقد المنطق الفيزيائي ("كل شغلة في شقة").

## 🔒 الحل الهندسي المطلق: السلسلة الحركية الأمامية (Forward Kinematics Chain)
في الهندسة الميكانيكية والروبوتات، **لا توجد قطعة واحدة تملك إحداثيات مستقلة**؛ كل قطعة تبدأ حصراً من نهاية القطعة السابقة:

```
[ سطح الأرض (Ground Line) ] ── (clamped: 0px gap)
       └── [ جنزير الحفار (Tracks) ]
             └── [ صينية الدوران (Turntable) ]
                   └── [ الكابينة وثقل الموازنة (Cabin) ]
                         └── مسمار المفصل الأول (Boom Base: P0)
                               └── ذراع الرفع (Boom) ──> المرفق (Elbow: P1)
                                     └── الساعد (Arm) ──> المعصم (Wrist: P2)
                                           └── المجرفة (Bucket) ──> أسنان الحفر (Teeth: P3)
```

### المعادلات الرياضية الإلزامية لحساب المواقع:
1. **قاعدة ملامسة الأرض:**
   $$\text{Track Bottom} = \text{Ground Line}$$
   *مستحيل فيزيائياً أن تطير الآلة فوق الأرض أو تغوص فيها.*

2. **نقطة مرفق الذراع (Elbow Pin):**
   $$P1_x = P0_x + L_1 \cdot \cos(\theta_1)$$
   $$P1_y = P0_y - L_1 \cdot \sin(\theta_1)$$

3. **نقطة معصم الساعد (Wrist Pin):**
   $$P2_x = P1_x + L_2 \cdot \cos(\theta_1 + \theta_2)$$
   $$P2_y = P1_y - L_2 \cdot \sin(\theta_1 + \theta_2)$$

4. **نقطة أسنان المجرفة الحافرة (Bucket Teeth):**
   $$P3_x = P2_x + L_3 \cdot \cos(\theta_1 + \theta_2 + \theta_3)$$
   $$P3_y = P2_y - L_3 \cdot \sin(\theta_1 + \theta_2 + \theta_3)$$

**النتيجة الهندسية:** مستحيل رياضياً للمجرفة أو الذراع أن تنفصل ولو بجزء من المليمتر، لأن موضعها هو دالة مباشرة في موضع المفصل الأب!

## 🛡️ بوابة التحقق الفيزيائي والهندسي التلقائي (Pre-Flight Kinematic Integrity Checker)
قبل اعتماد أو رندر أي كود SVG أو فيديو، يقوم المحرك تلقائياً بتشغيل فاحص التماسك الفيزيائي:

```python
class KinematicIntegrityChecker:
    @staticmethod
    def verify_excavator(excavator):
        # 1. فحص ملامسة الأرض
        ground_diff = abs(excavator.ground_y - excavator.track_bottom)
        if ground_diff > 0.5:
            # معالجة ذاتية فورية (Auto-Heal)
            excavator.clamp_to_ground()
            
        # 2. فحص تماسك المفاصل (Zero-Gap Rule)
        for name, pin, socket in excavator.joints:
            gap = math.hypot(pin[0] - socket[0], pin[1] - socket[1])
            if gap > 0.001:
                # معالجة ذاتية فورية
                pin.snap_to(socket)
```

### معايير بوابة التحقق (The 4 Integrity Gates):
1. **قاعدة الفراغ الصفري (Zero-Gap Rule):** المسافة بين مسمار الابن وتجويف الأب تساوي دائماً `0.000px`.
2. **قاعدة الارتكاز التثاقلي (Gravity Clamping):** جميع القواعد الإنشائية (قواعد الخزانات، جنازير الحفارات، أعمدة المظلات) تتطابق نهايتها السفلية مع خط السطح الحامل.
3. **تغطية المسامير الميكانيكية (Steel Pivot Caps):** رسم مسامير صلبة (`circle fill=#0f172a stroke=#94a3b8`) فوق كل مركز مفصل لإخفاء أي حواف تقاطع وتأكيد الارتباط العضوي.
4. **محاذاة المكابس الهيدروليكية (Piston Alignment):** جميع أسطوانات الزيت الهيدروليكي تمتد بدقة على الخط الواصل بين نقطة تثبيت الشاسيه ونقطة دفع الذراع.

## 💨 اقتران الانبعاثات والغازات بالفوهة (Emitter Coupling)
* ممنوع وضع الأبخرة أو الدخان بإحداثيات مستقلة.
* فوهة الخزان تحدد إحداثيات الصمام `(vent_x, vent_y)`.
* تنطلق جزيئات الغازات من نقطة الصمام وتتصاعد رأسياً بدقة متناهية.
