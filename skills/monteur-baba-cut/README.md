# 👑 Monteur Baba Cut | مونتير بابا كت (v6.6)

**المحرك السينمائي المستقل لإنتاج الموشن جرافيك ومونتاج الفيديو والريلز بالذكاء الاصطناعي (Universal Spatial Physics & Procedural Vector Edition).**

تحوّل هذه المهارة (`Skill`) أي وكيل ذكاء اصطناعي برمجي (**Antigravity, Claude Code, Codex, OpenCode**) إلى مخرج ومونتير سينمائي متكامل ("بابا المجال")، يبني المشاهد من الصفر بكود فيكتور صافي وفيزياء حقيقية، يضبط الكاميرا الماكرو ثلاثية الأبعاد، يجلب مؤثرات صوتية حقيقية من استوديوهات Openverse، ويصدر الفيديو النهائي **MP4** بجودة البث التلفزيوني محلياً 100% بدون الحاجة لعشر اشتراكات خارجية.

## 🎯 الترسانة الهندسية (26 محركاً فرعياً في 5 قطاعات)

### 1. 🏗️ محركات الرسم المتجهي والفيزياء الميكانيكية (6 محركات)
* **`ProceduralShapes Engine`:** رسم الأشكال والماكينات بالكود الصافي ومعادلات **Catmull-Rom Bezier Splines** (تجنب تشوهات الصور الثابتة).
* **`Mechanical Joint Rigging (J Helper)`:** نظام المفاصل الميكانيكية بدون أي انزياح دوراني (`(0,0)` Local Pivot) لتدوير التروس والأذرع حول مركزها بالمليمتر.
* **`Forward Kinematics Chain`:** سلاسل حركة ميكانيكية متصلة (قاعدة ← كابينة ← ذراع ← ساعد ← مجرفة).
* **`Kinematic Integrity Checker`:** بوابة تحقق إلزامية قبل الرندر لضمان ملامسة الأرض وتطابق المفاصل بنسبة خطأ **`Gap = 0.000px`**.
* **`Source-Emission Coupling Engine`:** اقتران الانبعاثات الفيزيائية (أدخنة، غازات، سوائل) بفوهاتها الحقيقية بدقة `1:1`.
* **`Subsurface Soil & Cutaway Generator`:** توليد طبقات التربة والصخور والمقاطع العرضية الهندسية تلقائياً.

### 2. 🎥 الإخراج السينمائي وحركة الكاميرا (6 محركات)
* **`Adaptive Macro Cinematography`:** كاميرا ماكرو ذكية (تقريب **`1.08x` إلى `2.5x`**) تجعل العنصر النشط يملأ `35% - 65%` من الكادر وتمنع اللقطات البعيدة المملة.
* **`3D Spatial Tilt Stage`:** مسرح ثلاثي الأبعاد بزوايا مداريّة (`RotateX`, `RotateY`) وعمق ميداني (`Depth of Field`).
* **`Anti-PPT Continuous Director`:** يلغي شرائح الباوربوينت الجامدة ويفرض وجود **≥ 10 عناصر حية متحركة** في كل ثانية.
* **`Virtual Camera Parallax 3D`:** حركة طبقات متعددة الأعماق لخلق بُعد بصري واقعي.
* **`Organic Film Grain Synthesizer`:** إضافة ملمس فيلمي عضوي لكسر البرود الرقمي.
* **`Social Safe-Zone Protector`:** حماية العناصر والنصوص من هوامش التيك توك، الريلز، والشورتس.

### 3. ⚡ فيزياء الحركة وتفاعل السوشيال ميديا (5 محركات)
* **`Motion.dev Spring Engine`:** فيزياء نوابض حقيقية بمعايير آبل اللمسية المرنة (`Stiffness, Damping, Mass`).
* **`Kinetic Typography Engine`:** نصوص متحركة ديناميكية تتزامن مع الصوت كلمة بكلمة.
* **`Interactive 3D Cursor & Touch System`:** محاكاة مؤشر ماوس ولمسات أصابع حية مع موجات ارتداد (`Touch Ripples`).
* **`Viral Doodle & Stickman Engine`:** تحريك شخصيات "ستيك مان" ورسوم دودل توضيحية خفيفة بالفيكتور.
* **`Live Counters & HUD Engine`:** عدادات أرقام ومقاييس ضغط وساعات حية تتغير بالزمن الحقيقي.

### 4. 🎧 هندسة الصوت وتصميم المؤثرات (4 محركات)
* **`Openverse Real Foley Engine`:** استعلام وتنزيل تلقائي لمؤثرات استوديو حقيقية مرخصة تجارياً (`CC0`) من Openverse مع كاش محلي سريع.
* **`Procedural Waveform Synthesizer`:** تخليق موجات صوتية برمجياً فورياً عند العمل أوفلاين.
* **`Auto-SFX Synchronizer`:** إضافة تلقائية لمؤثرات الانتقال والنقر والارتطام (`Whooshes, Pops, Clicks, Impacts`) متزامنة مع حركة الكاميرا.
* **`EBU R128 Broadcast Normalizer`:** ضبط وموازنة الصوت وفق معايير البث القياسية.

### 5. 🧠 الذكاء التحريري والمعالجة الآلية (5 محركات)
* **`Whisper Word-Level Aligner`:** تفريغ الكلام بدقة توقيت الكلمة الواحدة بالملي ثانية.
* **`AI Ambiguity & Typo Gate`:** بوابة تدقيق إملائي ولغوي غير هدّامة للتوقيتات.
* **`Zero-Setup Auto-Healing`:** تثبيت ذاتي تلقائي لأي أدوات ناقصة (`FFmpeg`, `Node.js`, `faster-whisper`, `numpy`).
* **`Existing Video Auto-Remaster`:** أخذ فيديو حالي وتنظيف صوته وتركيب كابشن سينمائي ومؤثرات عليه.
* **`HyperFrames Headless Chrome GPU Pipeline`:** خط رندر فريم-بفريم لتصدير MP4 فائق النقاء.

### ثانياً: التشغيل المباشر عبر سطر الأوامر (CLI Execution)

#### 1. وضع الاستيعاب الذكي التلقائي لمجلد كامل (`--input`):
```bash
python scripts/engine.py \
  --input "path/to/raw_folder" \
  --name "My_Viral_Reel" \
  --aspect "9:16"
```

#### 2. إنتاج فيديو موشن جرافيك من صوت (`--audio`):
```bash
python scripts/engine.py \
  --audio "path/to/voiceover.wav" \
  --name "Monteur_Baba_Ad" \
  --style "viral_doodle" \
  --physics "motion_dev" \
  --aspect "9:16"
```

#### 3. مونتاج وإعادة هندسة فيديو حالي (`--video`):
```bash
python scripts/engine.py \
  --video "path/to/raw_footage.mp4" \
  --name "Mastered_Clip" \
  --style "pastel_director" \
  --aspect "9:16"
```

#### 4. جدول خيارات سطر الأوامر الكامل (CLI Parameters):

| المعامل (`Flag`) | الوظيفة والشرح | القيم المدعومة |
|---|---|---|
| `--input` | تمرير مجلد كامل؛ يمسحه المحرك ويفصل الصوت والفيديو والصور تلقائياً | مسار مجلد أو ملف |
| `--audio` | المسار إلى ملف التعليق الصوتي الخام | `.wav`, `.mp3`, `.m4a` |
| `--video` | المسار إلى فيديو حالي لعمل مونتاج وكابشن حركي له | `.mp4`, `.mov`, `.mkv` |
| `--images` | مسار صور أو مجلد صور لإدخالها في المشهد | مسارات مفصولة بفاصلة |
| `--name` / `--project` | اسم المشروع لإنشاء مجلده المنعزل الموحد | نص (مثال: `iPhone18_Ad`) |
| `--dir` | المجلد الرئيسي للمشاريع (الافتراضي: `projects`) | مسار مجلد |
| `--aspect` | أبعاد الفيديو المطلوبة | `9:16` / `16:9` / `1:1` |
| `--style` | الهوية البصرية للمشروع | `pastel_director` / `cinematic_noir` / `cinematic_film` / `viral_doodle` |
| `--physics` | محرك فيزياء الحركة | `motion_dev` (نوابض مرنة) / `classic_gsap` |
| `--preview` | استخراج لقطات فحص سريعة (`Snapshots`) قبل الرندر الكامل | Flag |
| `--transcript` | تمرير ملف JSON مفرغ ومعتمد مسبقاً لتخطي Whisper | مسار `.json` |
| `--corrections` | تصحيح كلمات محددة إملائياً قبل التوليد | `'كلمة1=صح1,كلمة2=صح2'` |

## ⚖️ القوانين الفيزيائية والهندسية الخمسة للمحرك

1. **قانون محور الارتكاز الميكانيكي العام `J(el, tx, ty)`:** تدوير كافة المفاصل والعناصر من نقطة الأصل المحلية `(0,0)` لمنع أي انزياح أو تباعد.
2. **قانون الاقتران المطلق بين المصدر والمنبثق:** ربط الدخان، الغازات، السوائل، والشرارات بنقطة خروجها الحقيقية بنسبة `1:1`.
3. **قانون الكاميرا الماكرو التكيفية (`1.08x - 2.5x`):** إبقاء العنصر النشط في مركز الاهتمام ومنع اللقطات البعيدة الباهتة.
4. **قانون الرسم الرياضي النقي:** الاعتماد الكامل على معادلات متجهات SVG و **Catmull-Rom Bezier Splines**.
5. **دستور منع العرض التقديمي (Anti-PPT):** حظر الشرائح الجامدة وضمان استمرارية الحركة بوجود **10+ عناصر حية** في كل كادر.
