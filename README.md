## 🛠️ التثبيت السريع للوكلاء (Quick Installation)

تتبع هذه المهارات المعيار المفتوح لمهارات الوكلاء ([Agent Skills Standard](https://agentskills.io))؛ لتثبيتها يكفي نسخ مجلد المهارة المطلوب إلى مسار المهارات الخاص بأداتك:

### 1. في Antigravity / Gemini:
انسخ مجلد المهارة إلى المسار العالمي:
```bash
~/.gemini/skills/<skill-name>
```
أو داخل مشروعك مباشرة في `.agents/skills/<skill-name>`.

### 2. في Claude Code:
لجميع مشاريعك:
```bash
mkdir -p ~/.claude/skills/<skill-name>
cp -r skills/<skill-name>/* ~/.claude/skills/<skill-name>/
```
أو لمشروع محدد:
```bash
mkdir -p .claude/skills/<skill-name>
cp -r skills/<skill-name>/* .claude/skills/<skill-name>/
```

### 3. في OpenAI Codex CLI:
```bash
mkdir -p ~/.codex/skills/<skill-name>
cp -r skills/<skill-name>/* ~/.codex/skills/<skill-name>/
```

### 4. في Cursor / Windsurf:
انسخ المجلد داخل `.cursor/skills/<skill-name>` أو المجلد المعتمد لمهارات الوكيل في بيئتك.
